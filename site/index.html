Evolution

3.0 → 4.0 → 4.11.0
一次彻底的重写

回收站挂件从 Python 原型到纯 C 单文件，三年里最重要的三次跃迁， 每一代都解决了上一代最痛的那个问题。

  1. 3.0

    Python 原型 · 方向验证

    用 PySide 快速验证「玻璃 + 桌面挂件」的可行性：材质方向成立，但 PyInstaller 打包 30 MB+、冷启动 1–2 秒、常驻内存 150 MB， 对一个桌面小挂件来说太重了。

  2. 4.0

    纯 C 重写 · 0.83 MB 单文件

    GDI+ 分层窗口全自绘：圆角盒 SDF 蒙版、背景实时采样、边缘折射色散； 无框架、无运行时依赖，exe 0.83 MB、启动即显（<100 ms）、空闲 CPU ≈ 0%； 自带无边框拖拽、CF_HDROP 拖放回收、托盘常驻与单实例。

  3. 4.5–4.9

    玻璃打磨 · 稳定 60 fps

    面板缓存 + 命中测试：右键菜单从 30 fps 抖动到 60 fps 稳定； 抓屏瞬间临时排除自身窗口（WDA），截图可见且零拖影/鬼影； φ 间距与同心圆角上线，图标左/上/下留白恒等。

  4. 4.10

    磨砂可见性重构 · 胶囊滑块

    覆盖率改为「高下限 + 窄跨度」（0.62 + 0.38 × 透明度）， 透明度拉低也始终有磨砂；分段控件重做为 2 px 内缩的饱满胶囊； 圆角无级 12–52 px，间距随圆角按 φ 联动。

  5. 4.11

    MiSans 嵌入 · 排版收口

    全应用切换小米官方 MiSans，文字改为实测高度视觉居中（修复中文偏高 1–2 px）； 只嵌入界面用到的 236 个字符，双字重子集共 124 KB， exe 0.98 MB 单文件自带字体，换机换语言字形都不跑。
