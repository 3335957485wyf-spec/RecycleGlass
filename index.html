4.12.2 最新

透明度全程有效 · 零空转 · 体积减半

未置顶时只要窗口碰到卡片，透明度滑块就失效——现在滑块在任何模式下都有效： 卡片下方真的有窗口时，玻璃自动把它磨砂进背景（与「总在最前」同一来源）， 锐利文字不再漏出；窗口移走后无感切回桌面采样。同时合并 4.12 的全部优化： 画面无变化就跳过整帧合成（空闲重绘 1.4 → 0 帧/秒），回收站改事件驱动 + 退避轮询， 空闲 CPU 1.37% → 0.5%；exe 998,744 → 458,752 字节（约 -54%），启动 138→132ms； 修复菜单悬停跨行串色，卡片帧逐像素一致。

4.11.7

玻璃背景跟上 60 帧

抓帧节奏从 120ms（≈8 fps）改为 6ms 节拍，并去掉被合成器锁住的 CAPTUREBLT： 视频/动画在卡片后面时上屏 55–58 帧/秒；静止时仍退避到 400ms（约 1 帧/秒、CPU≈0）。

4.11.6

置顶才玻璃其他应用

勾选「总在最前」时采样实时屏幕，后面的窗口会被一起磨砂；未置顶时只采样桌面， 并且检测到有窗口在卡片后面就把本体烘焙为不透明——窗口再也不会「透」进玻璃 （实测未置顶时逐像素差异 0.00，置顶时有 65% 像素变化）。

4.11.5

只玻璃桌面（含图标）· 一批细节修复

卡片改为让桌面窗口自己渲染（PrintWindow）：壁纸与桌面图标一起进入玻璃，其他软件窗口被排除， 按事件重建、整屏一次约 30ms。同版合并的修复：圆角滑块与分段控件左右端对齐（≤1px）、 全部文字改用「墨迹居中」（偏差 0.00px）、清空确认长文案自动分行不再被裁切。

4.10.0

磨砂全程可见 · 胶囊滑块重设计

覆盖率改「高下限 + 窄跨度」，透明度拉低也有磨砂；间距加「黄金下限」，任意圆角下留白都恒等。
